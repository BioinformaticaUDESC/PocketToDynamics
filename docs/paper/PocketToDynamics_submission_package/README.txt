PocketToDynamics manuscript submission package

Manuscript/ contains the complete editable Word article with continuous left-margin line numbering, a PDF reading copy, and the Markdown source. Figures/ contains the nine individual figure images in the order they appear in the article.

The Word and PDF manuscripts embed the figures in place; separate copies are provided for submission systems that request figure files individually.

Current manuscript counts: 330-word abstract; 7,419 main-text words before references; nine figures; six tables; 27 references. Please consult FRONTIERS_SUBMISSION_NOTES.md in the repository for unresolved submission requirements and collection-scope caveats.
